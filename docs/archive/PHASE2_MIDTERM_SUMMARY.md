### 2. FinBERTAnalyzer（情绪分析器）

**功能**：基于深度学习的情感分析

**核心技术**：
- 开源中文FinBERT模型（uer/finbert-cn）
- GPU加速支持
- 批量处理能力

**关键指标**：
- sentiment_score: -1到1
- label: positive/neutral/negative
- confidence: 0到1

---

### 3. L2StrategyFactor（战略执行层因子）

**功能**：整合承诺和情绪，评估战略执行情况

**核心技术**：
- 承诺兑现率计算
- 情绪得分整合
- 加权评分机制

**关键指标**：
- revenue_fulfillment_rate: 营收兑现率（0-200+%）
- profit_fulfillment_rate: 利润兑现率（0-200+%）
- management_sentiment: 管理层情绪（-1到1）
- strategy_execution_score: 综合评分（0-100）

**计算公式**：
```python
兑现率 = (实际增长率 / 承诺增长率) * 100%
综合评分 = 0.7 * 兑现率映射分 + 0.3 * 情绪映射分
```

## ⚠️ 遇到的问题与解决

### 1. Python版本兼容性

**问题**：Python 3.14与torch 2.12存在DLL加载问题（WinError 1114）

**解决方案**：
- 测试环境使用Mock完全隔离torch
- 生产环境建议使用Python 3.10/3.11
- 记录在文档中作为已知限制

### 2. Mock数据结构复杂性

**问题**：pandas DataFrame的Mock需要正确模拟`iloc`和`to_dict`

**解决方案**：
- 使用真实的pandas DataFrame进行Mock
- 通过`side_effect`实现条件返回
- 确保Mock行为与实际一致

### 3. 财务数据获取逻辑

**问题**：初始实现使用`df.to_dict('records')[0]`，在空DataFrame时会报错

**解决方案**：
- 改为`df.iloc[0].to_dict()`
- 增加`df is None`检查
- 完善异常处理
