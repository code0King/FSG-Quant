## 1. 产品概述

### 1.1 产品定位
一个轻量级的A股上市公司量化分析工具，基于"财报-战略-治理"三维视角，将年报信息自动化转化为可回测的Alpha因子体系。采用本地化部署，无需复杂的基础设施，适合个人研究者快速上手。

### 1.2 核心价值
- **零运维成本**：无需数据库服务器、API服务、容器编排
- **交互式分析**：通过Jupyter Notebook灵活探索数据
- **一键执行**：简单脚本完成从数据下载到因子计算的全流程
- **透明可控**：所有代码和数据结构清晰可见，便于定制修改

### 1.3 功能范围
✅ **包含**：
- L1/L2/L3三层因子计算
- FinBERT-CN情绪分析
- 施密特正交化
- 进攻型/防御型打分卡
- Qlib回测引擎
- 行业差异化阈值

❌ **不包含**：
- API服务（无远程调用需求）
- 多用户并发支持
- 实时监控告警
- Web前端界面
- 做空策略

## 2. 技术架构

### 2.1 技术栈

| 组件 | 技术选型 | 说明 |
|------|---------|------|
| 数据存储 | SQLite + Parquet | 轻量级、零配置 |
| 数据处理 | Pandas + NumPy | Python数据分析标准库 |
| NLP引擎 | FinBERT-CN | HuggingFace预训练模型 |
| 量化回测 | Qlib | 微软开源量化平台 |
| 交互界面 | Jupyter Notebook | 交互式数据分析 |
| 可视化 | Matplotlib + Seaborn | Python绘图库 |
| PDF解析 | pdfplumber + PyMuPDF | 表格+文本提取 |

## 3. 功能需求（保持v1.0核心逻辑）

### 3.1 L1业绩验证层
- ROE、ROA、ROIC、毛利率等7个因子
- 毛利率分级评价（行业差异化）
- 盈利质量综合评分（0-100）

### 3.2 L2战略执行层
- FinBERT-CN情绪分析
- 战略承诺抽取（正则表达式方案A）
- 战略兑现率、研发强度、CAPEX兑现率

### 3.3 L3治理排雷层
- 大股东质押率监控
- 审计意见一票否决
- 核心人员流失率

### 3.4 因子合成
- 施密特正交化
- 进攻型/防御型打分卡
- 风险分级（红橙黄绿）

### 3.5 回测引擎
- Qlib集成
- 年度调仓（T+1年5月）
- Sharpe比率、最大回撤等指标

## 5. 数据需求

### 5.1 必需数据源
- 年报PDF（巨潮资讯）
- 财务数据（SQLite存储）
- 行情数据（Tushare导出为Parquet）
- 申万行业分类（CSV映射表）

### 5.2 数据量估算
- 年报PDF：5000只 × 5年 = 25000份，约50GB
- SQLite数据库：约500MB
- Parquet因子文件：约200MB
- 行情数据：约5GB
